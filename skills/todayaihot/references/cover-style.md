# codebase-style 封面规范

参考外部发布工具 `social-auto-upload` 的 `skills/video-upload` 封面规则，并在 Remotion 中使用 `components/CodebaseCover.tsx` 复用。

- 背景：深蓝径向渐变，叠加细网格；顶部蓝/黄光带，底部黄色光带；
- 主标题：蓝 → 黄 → 橙渐变大字，宽度控制在画布约 72%–88%；
- 副标题：白色粗体，包含日期、星期和精选条数；
- 标签：浅蓝色小标签，例如“AI 热点速览”；
- 胶囊：黄色描边和黄色文字，例如“AI 头条 · 1 分钟速览”；
- 署名：浅蓝色“翻奇兽AI”；
- 首帧静音图与 3:4、4:3、16:9 封面必须同源生成；
- 禁止使用视频首帧截图直接作为平台封面，也不要用 FFmpeg 裁切图绕过重绘。

**文字宽度保护（2026-10-12 glm53 封面截断事故沉淀，`CodebaseCover.tsx` 已内置）**：主标题/副标题/胶囊都经 `fitFontSize` 估宽缩字号（CJK≈1.0em、ASCII≈0.56em、粗体 +6% 余量，下限各 64/34/30），并改用 `wordBreak: "break-word"` 兜底换行；**禁止 `whiteSpace: "nowrap"`**——外层 `overflow: "hidden"` 会把超宽文案静默裁掉且无任何报错。重生成后逐张目检 + 像素检测：左右 3% 边缘区零文字亮像素、内容最窄边距 ≥6% 画布宽，不满足就精简文案再重生成。
